# Dataset location

The project plans to use the **Chest X-Ray Images (Pneumonia)** dataset from Kaggle. When dataset acquisition is approved in a later task, place the original files under `data/raw/`. Any reproducibly derived data should be written under `data/processed/`.

The expected binary classes are:

- `NORMAL`
- `PNEUMONIA`

Dataset files must not be committed to Git. Both `data/raw/` and `data/processed/` are ignored, while this documentation remains tracked.

**Current status:** The dataset has **not** been downloaded. No image files or derived dataset artifacts are present as part of project initialization.
